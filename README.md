# sane-next

Clean-sheet successor to Sane.

This repo starts intentionally small. It does not inherit the current Sane codebase, and it does not start with a repo-local TODO ledger, generated planning scaffold, or broad framework structure.

## Tracking

- **Active work:** GitHub Issues
- **Significant decisions:** `docs/adr/`
- **Progress evidence:** commits and pull requests linked to issues

GitHub Projects is optional later if issue volume or parallel work makes it clearly useful. It is not the default.
