# Documentation map

Use this directory for durable project documentation only. Do not add ad-hoc plans, TODOs, research dumps, or agent memory files.

## Where to look

- `roadmap/ROADMAP.md` — living product direction, release discipline, and evidence for open/completed roadmap items.
- `adr/` — accepted Architecture Decision Records. Use for durable choices and rationale.
- `standards/` — normative repo rules for tracking, implementation runs, and instruction surfaces.
- `reference/` — factual background that is useful but not operational policy.

## Agent workflow

1. Read `TRACK.toml` first for the active execution window.
2. Read `README.md` for current user-facing behavior and commands.
3. Follow only the docs referenced by the active slice unless the user asks for broader research.
4. When changing docs, keep content in this fixed structure and remove stale or contradictory nearby text.
