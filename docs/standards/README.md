# Standards

This directory owns normative repo rules for contributors and agents.

## Files

- `DOCS-STRUCTURE-STANDARD.md` — where documentation belongs and when to add directory READMEs.
- `TRACK-STRUCTURE-STANDARD.md` — the allowed shape of `TRACK.toml`.
- `INSTRUCTION-SURFACE-STANDARD.md` — rules for AGENTS files, skills, prompts, and agent definitions.
- `IMPLEMENTATION-RUN-PROTOCOL.md` — durable implementation-slice discipline for bounded work.

Standards should be short, enforceable where practical, and referenced instead of duplicated.
